# QuickLinker
类似TurboLaunch的快捷启动管理软件

# 免责声明
- [官方网站](https://www.savardsoftware.com/turbolaunch/)
- 官方已不再维护该软件，本人基于多屏显示器呼出位置不对原因，用C#重现该软件；使用其中icon以及audio资源，如有侵权请联系删除！

# 新功能
- 插件支持SVG图标
- 插件支持图片略缩图图标
- 支持解析Steam平台中游戏快捷图标到本体文件
- 支持无缝迁移TurboLaunch配置到QuickLinker
- 完美支持多显示器唤出到鼠标位置
- 在截屏或录屏中不可见
- 支持URI调用容器中启动项(`quicklinker:{guid}`)
- 软件及容器配置存软件同目录json文件(忘备份的痛)
- 设置界面即调即生效
